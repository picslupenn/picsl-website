Software

PICSL develops and distributes open-source software for medical image analysis.

ITK-SNAP

Interactive open-source application for segmenting structures in 3D and 4D medical images, with over 10,000 monthly downloads.

software
ANTs

Advanced Normalization Tools: accurate diffeomorphic image registration, template building and image analysis.

software
FireANTs

Fast, training-free diffeomorphic registration on the GPU, using adaptive Riemannian optimization.

software
Greedy

Very fast CPU-based affine and deformable registration for pipelines that register many images in parallel.

software
Convert3D

Command-line Swiss army knife for medical image processing that complements ITK-SNAP.

software
ASHS

Automatic segmentation of hippocampal subfields and medial temporal lobe cortices in MRI.

software
PHAS

Web-based platform for archiving and annotating digital histopathology images and training deep learning classifiers.

software
Camino

Open-source toolkit for diffusion MRI simulation, image reconstruction and tractography.

software
HistoloZee

Interactive histology reconstruction, MRI co-registration and manual segmentation of large histology datasets.

software
LESYMAP

Univariate and multivariate lesion-symptom mapping of brain regions whose damage causes specific cognitive deficits.

software
LINDA

R toolkit for automatic segmentation of chronic stroke lesions.

software
TLEprediction

Predicts the side of seizure onset in temporal lobe epilepsy from PET asymmetries.
